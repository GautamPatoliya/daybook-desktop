# Daybook 2.0 - Vision

**Name:** Daybook 2.0  
**Baseline:** Daybook 1.1.1  
**Audience:** Indian office employees who log daily work and send manager updates  

---

## Thesis

Daybook 2.0 sharpens the app as a **Kanban + email draft helper**:

- Comfortable capture (large editor only)  
- Frictionless styled Gmail handoff  
- Basic carry-forward of unfinished tasks  
- Default theme polished for all-day office use  
- Updates that feel modern on Windows; honest assisted path on unsigned Mac  

**Primary professional output remains the EOD email.** Everything else exists to make that email accurate, easy, and on time.

---

## What 2.0 is not

- Not a cloud multi-user PM tool  
- Not Jira / Linear / Asana clone  
- Not gamification (streaks, badges, flames)  
- Not “more themes” as the main roadmap  
- Not surveillance HR software

---

## Non-negotiable constraints

1. Local-first core (no account required for daily use).  
2. Email is the primary professional output.  
3. Editor only - no dual bullets+editor UI.  
4. Indian 12-hour time in all user-facing UI.  
5. Both Default and Spider-Verse themes remain supported.  
6. No silent data loss; migrate old day files.  
7. Mac update honesty until Apple signing exists.  
---

## Success (2.0 complete)

- User writes in one large editor; Daybook structures mail.  
- Open Gmail shows styled structured body with near-zero paste friction.  
- Long Drive links never break layout.  
- Times always show like `9:15 AM`.  
- Categories managed like projects (add/edit/delete/reorder).  
- Default theme feels polished for all-day use.  
- Update on start popup; Windows installs on restart; Mac gets clear assisted path.
